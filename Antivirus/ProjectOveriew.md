🛡️ Project Overview

This repository is an experimental project aimed at building a custom antivirus and threat detection engine. The goal is to draw inspiration from existing industry standards:

    Static Analysis (Inspired by ClamAV): Scanning files and directories for known malware signatures and patterns.

    Runtime Monitoring (Inspired by Falco): Observing system activity and behavior to detect suspicious actions in real-time.

Note: This is a learning/open-source project intended to explore how modern security engines operate under the hood.
